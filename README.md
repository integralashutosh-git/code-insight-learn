# CodeInsight

> **Code Smarter. Learn Deeper.**

CodeInsight is an AI-powered programming learning platform designed for beginners. Instead of compiling code, it explains every line, detects concepts, generates revision notes, and recommends the most relevant YouTube lectures with exact timestamps.

## 🌐 Live Demo

**Live App:** https://code-insight-learn.lovable.app

## ✨ Features

- AI-generated comments above every line
- Real-time concept detection
- Smart YouTube lecture recommendations with timestamps
- Automatic revision notes
- Multi-language support (Java, Python, C, C++, JavaScript)
- Monaco Editor with VS Code-inspired UI
- Light & Dark mode

## 🛠 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Monaco Editor
- Vite

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/codeinsight.git
cd codeinsight
npm install
npm run dev
```

## 🎯 Vision

Students write code → AI understands it instantly → explains every line → detects concepts → recommends the perfect lecture.

> **Note:** CodeInsight is a learning platform, not an online compiler. It never executes user code.
