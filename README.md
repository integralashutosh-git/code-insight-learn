# CodeInsight

### Full Lovable Prompt — CodeInsight



### Project Name



CodeInsight



Tagline: Code Smarter. Learn Deeper.



### Vision



Build a premium AI-powered programming learning platform for beginners. This is NOT an online compiler and must not include Run, Compile, or Execute buttons.



The platform's purpose is simple:



> Students write code → AI understands it instantly → Adds comments above every line → Detects concepts → Recommends the exact YouTube lecture with timestamps.



Use React + TypeScript + Tailwind + Monaco Editor with a modern Apple × VS Code inspired UI.
